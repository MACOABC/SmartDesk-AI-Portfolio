# SmartDesk AI — Publication checklist

El candidato debe permanecer **PRIVATE** hasta que todos los controles manuales
estén completados y el propietario autorice explícitamente la publicación.

## Technical readiness

- [x] MIT LICENSE.
- [x] README final para recruiter y engineer.
- [x] Arquitectura real documentada.
- [x] Métricas verificadas contra evidencia original.
- [x] Limitaciones conocidas visibles.
- [x] Historial sanitizado.
- [x] CI determinista PASS.
- [x] Cero production secrets.
- [x] Aislamiento de producción.
- [x] Release notes de `v1.1.0` preparadas.
- [x] Estrategia `v1.0` / `v1.1.0` documentada.
- [x] Fresh-clone y security scan ejecutables.

## Manual publication controls

- [ ] Screenshots reales capturados e insertados.
- [ ] Cada screenshot revisado al 100 % de zoom.
- [ ] Demo de aproximadamente 3 minutos grabada.
- [ ] Video revisado cuadro por cuadro.
- [ ] README renderizado revisado con los assets finales.
- [ ] Fresh clone final después de incorporar assets.
- [ ] Tag `v1.1.0` autorizado.
- [ ] GitHub Release `v1.1.0 — Portfolio Release` autorizada.
- [ ] Owner approval para publicar.
- [ ] Visibility cambiada explícitamente a PUBLIC.

No marcar controles manuales por inferencia ni crear tag, release o cambio de
visibilidad antes de la autorización final.
